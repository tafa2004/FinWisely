 #FinWisely

## Secure Digital Banking Transaction Management System

FinWisely is a Java-based banking transaction management system developed using MySQL and JDBC.

The project focuses on secure database access, transaction integrity, authentication, access control and audit logging.

## Technology Stack

- Java 21
- Maven
- MySQL
- JDBC
- JUnit 5
- Git and GitHub

## Project Structure

- src/main/java - Application source code
- src/test/java - Automated tests
- database - Database scripts (to be added by the team)

## Setup

1. Install JDK 21.
2. Install Maven.
3. Install MySQL Server and MySQL Workbench.
4. Clone this repository.
5. Open the project in VS Code.
6. Run mvn clean test.
